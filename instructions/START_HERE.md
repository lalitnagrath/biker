# BikeReview Project

## Before doing anything

Read these files in order:

1. instructions/PROJECT.md
2. docs/ARCHITECTURE.md
3. docs/CURRENT_STATE.md
4. instructions/ROADMAP.md
5. instructions/AI_RULES.md
6. instructions/CODING_RULES.md

The current milestone is tracked at the repository root:

- MILESTONE_8.md (currently active)
- MILESTONE_7.md (completed)
- MILESTONE_5.md (completed)

These files are the single source of truth.

## Project Rules

- Do not redesign the architecture unless explicitly requested.
- Continue from the current milestone.
- Never duplicate existing functionality.
- Always reuse existing services, repositories and models.
- UI must never access the database directly.
- The Service layer is mandatory.
- SQLite is the source of truth.
- HTML is generated from the database.
- The deployed website is static HTML only.
- Add tests for new functionality.
- Update docs/CURRENT_STATE.md after completing a milestone.
