# Editorial System Roadmap

## Instructions

Read this file before starting work.

### Rules

- Work through NEXT_TASKS.md from top to bottom.
- Complete one task at a time.
- Test each completed task.
- Mark the task as completed.
- Continue to the next unchecked task automatically.
- Verify whether functionality already exists before implementing.
- Search the codebase before writing new code and extend existing implementations whenever possible.
- Reuse existing code whenever possible.
- Do not create duplicate implementations.
- Do not remove existing functionality unless instructed.
- If architectural changes are required, document them in ARCHITECTURE.md.
- Stop only if:
  - clarification is required,
  - a test cannot be resolved,
  - or a major architectural decision is needed.
